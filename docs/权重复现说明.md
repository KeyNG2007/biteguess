# 模型权重获取与复现

本文供审核者准备运行环境。仓库不包含数据集与权重；目前未提供五类微调权重的公开下载链接，审核者可按以下步骤重新训练。安装依赖的命令见 README，项目使用 Python 3.12 环境。

## 公开预训练权重

在仓库根目录运行以下命令，Ultralytics 会在文件缺失时联网获取对应公开权重：

```powershell
.\.venv\Scripts\python.exe -c "from pathlib import Path; from ultralytics import YOLO, SAM; Path('models').mkdir(exist_ok=True); YOLO('models/yolo11n.pt'); SAM('models/sam2.1_t.pt')"
```

`yolo11n.pt` 为通用预训练检测模型，仅用于初始化训练，不可替代五类 `best.pt`。`sam2.1_t.pt` 为 SAM2.1 tiny 提示分割模型，可直接用于网页分割。两种模型通过 Ultralytics 使用，模型和框架许可须遵循其各自条款。

## 五类检测模型

从 [UEC FOOD 100 官方页面](http://foodcam.mobi/dataset100.html) 下载数据，将压缩包保存为 `data/dataset100.zip`，无需手工解压。数据按官方非商业研究用途使用。

```powershell
.\.venv\Scripts\python.exe scripts\prepare_uecfood100.py
.\.venv\Scripts\python.exe scripts\train_yolo_baseline.py
```

转换使用 `configs/detection_classes.json`，合并所选类别标注并按像素内容去重，再以 seed 42 划分训练、验证和测试集。训练在 CPU 上进行 10 轮，输入尺寸 320、batch 4；本项目环境耗时约 23 分钟。输出权重为 `models/yolo_runs/baseline_10epochs/weights/best.pt`。

转换脚本拒绝覆盖已有清单。重训应使用干净的实验副本，避免覆盖原始报告；Ultralytics 在训练目录重名时也可能生成带编号的新目录，此时需要将选定的最佳权重放到应用预期路径。不同硬件或库版本下不保证训练结果逐位相同。
